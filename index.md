# Lidarion Hexmap Studio

**Lidarion Hexmap Studio** is an Inkarnate-style cartography suite and world-building engine designed specifically for **Foundry Virtual Tabletop (v14)**. It allows Gamemasters to craft, paint, detail, and explore vast, playable hexmaps directly within Foundry—without needing external image editors or third-party mapping software.

{: .fs-6 .fw-300 }

---

## Key Features at a Glance

| Feature | Description |
|:---|:---|
| **Dedicated Hexmaps Directory** | An independent Foundry sidebar tab (`fa-hexagon-nodes`) keeps your world maps organized and separate from standard tactical battlemaps. |
| **Full-Screen Cartography Studio** | Intuitive painting suite with Brush, Flood Fill, Eraser, and Eyedropper tools, supporting brush radii from 1 to 6 hexes. |
| **4 Layer Cartography Engine** | Build intricate overland maps using Standard Terrain, Custom Terrain, Objects/Props, and Vector Roads & Rivers. |
| **In-Engine Custom Asset Workshop** | Turn any illustration into a standard, gapless hextile with visual Core Hex, Overhang, and Cutoff masking zones. |
| **1-Terrain + 1-Object Stacking Engine** | Strict cell stacking rule: exactly one terrain tile and one object prop per hex cell, ensuring safe, non-destructive editing. |
| **Interactive Scene Hub (Codex)** | A visual world atlas for your territories featuring custom art banners, rich-text lore notes, linked battlemap transitions, and drag-and-drop document binders. |
| **Discrete Hex Fog of War** | Hex-based exploration reveals whole hexagonal tiles as tokens travel, replacing awkward circular vision bubbles. |
| **Group Token Travel** | Animated, space-by-space party token movement across hexes at configurable travel speeds. |
| **High-Performance Scene Baking** | Flatten maps with up to 250,000+ hex tiles into a single high-resolution WebP background for lag-free 60 FPS gameplay. |
